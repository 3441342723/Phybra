# 高中物理工作台

面向高中物理的交互式网页原型，参考 GeoGebra 的对象、参数与图形联动方式。支持搭建场景、调整参数，并查看解析答案、推导、运动动画与曲线。

## 当前能力

- 二维场景编辑、对象列表、属性面板、参数绑定与滑块。
- 「对象」中创建小球、物块、绳、杆和斜面；斜面设为 0° 就是水平面。「场」放置重力场、电场、磁场或点源。小球属性里的「带电」开关控制是否受电磁力，勾选后可输入正或负的电荷量。
- 场可重叠，并使用全局、矩形、圆形或简单多边形范围。绘制多边形时可以先选场类型；在场属性中的「场强分布」可切换匀强与线性渐变。点质量产生平方反比引力，点电荷产生平方反比电场。小球设置初速度并加入全局竖直重力场即可做平抛、斜抛。
- 「载入示例 → 电磁学」包含平行板加速与偏转、匀强磁场出界与半圆返回、复合场速度选择、速度选择后进入磁场，以及裁剪点电荷场。矩形电场可按板间电压和间距计算场强。用「待求量」选择指定场区的进出场，可查看时间、位置、速度和场内位移；单段纯磁场圆弧还给出半径与转角。
- 初始位置与速度编辑、画布缩放平移、撤销与重做。
- 匀变速直线运动、抛体运动、单物体斜面摩擦求解。
- 运动轨迹、时间轴、曲线和公式推导。播放倍率默认 1×，可手动输入正数（例如 0.1× 或 1e-6×），不改变时间轴和求解结果。
- 能量曲线：在「曲线」窗口切换到「能量–时间」，随时间轴查看动能、重力势能、机械能与摩擦耗散；也可在「待求量」指定时刻或最高点、落地等事件计算能量和区间做功。支持有质量的水平面、斜面、连续轨道和抛体场景。
- 场景浏览器本地保存、JSON 导入导出。
- AI 建模草稿的预览与应用入口。

平行板采用理想匀强电场，忽略边缘效应；到达板边视为离开场区，不模拟与极板碰撞。电磁模块目前处理二维单粒子，不涉及电路、电磁感应或带电粒子之间的相互作用。

**AI 读题目前默认使用预设演示数据，尚未接入真实的云端识别服务。** 设置 `VITE_AI_ENDPOINT` 后，前端会向指定服务发送题目与可选图片，并接收场景草稿。当前仓库不包含该服务端实现，也尚未完成 Qoder Sites 部署。

## 本地运行

需要支持 Vite 5 的 Node.js，建议使用 Node.js 22 LTS 或更高版本。

```sh
npm ci
npm run dev
```

浏览器打开终端显示的本地地址，默认是 http://127.0.0.1:5173。

## 检查与构建

```sh
npm test
npm run typecheck
npm run build
npm run preview
```

构建目录为 `dist/`。当前测试覆盖求解器、单位、参数路径、状态管理、交互布局，以及动画与求解结果的一致性。

## 可选 AI 服务

在本地 `.env.local` 中配置：

```dotenv
VITE_AI_ENDPOINT=https://your-backend.example/api/interpret
```

接口接受 JSON 格式的 POST 请求，字段为 `text`，以及可选的 `imageBase64`（标准 Base64 编码）和 `imageName`。成功响应为 JSON `SceneDraft`，字段为 `source`、`scene`、`known`、`assumed`、`unknown`、`uncertain` 和 `warnings`。其中 `scene` 使用 version 2；缺少的物理数值用 `null` 表示。草稿中的 `known`/`assumed` 项包含 `path`、`label`、`value`，并可附带 `quote`/`basis`；`unknown` 项包含 `path` 和 `label`。路径必须引用草稿中的场景对象或受支持的求解目标。图片大小上限为 4 MiB，客户端请求超时为 30 秒。HTTP 429 显示额度耗尽，其他非成功状态显示服务不可用。

客户端会对 AI 响应和导入场景执行运行时校验，包括字段类型、枚举、有限数字、唯一 ID、场景引用、参数绑定和草稿路径。结构错误会在进入预览前拒绝。物理条件缺失仍保留在场景草稿中，交由本地求解器报告并由用户补充。取消请求不会将迟到响应写入草稿；AI 只负责生成场景草稿，答案仍由本地确定性求解器计算。

所有 `VITE_` 变量都会进入浏览器构建，只能配置公开服务地址；AI 服务密钥应保存在后端。公开上线前需实现服务端访问控制、限流与调用额度控制。

## 项目结构

- `src/model`：场景类型、单位、几何、参数与模型校验。
- `src/solver`：物理解析求解器。
- `src/state`：编辑状态、历史记录与持久化。
- `src/ui`：画布、对象与属性、动画、曲线和结果面板。
- `src/ai`：AI 接口客户端与演示草稿。
- `tests`：自动测试。
